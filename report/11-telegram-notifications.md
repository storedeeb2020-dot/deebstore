# خريطة طريق وخطة تنفيذ نظام إشعارات تليجرام المباشرة للطلبات 📱⚡
## Telegram Live Order Notifications Plan — DEEB STORE

---

## 📌 1. نظرة عامة على النظام (System Overview)
نظام الإشعارات المباشرة يتيح لـ **عم ناصر الديب (أدمن المتجر)** وفريق المبيعات تلقي **إشعار فوري لحظي على تطبيق تليجرام (Telegram)** بمجرد قيام أي عميل بإتمام طلب جديد على متجر **DEEB STORE**.

تصل الرسالة فوراً بتنسيق أنيق وشامل يحتوي على:
- 🆔 **رقم الطلب الكودي**
- 👤 **بيانات العميل** (الاسم، رقم الهاتف، رابط واتساب مباشر)
- 📍 **العنوان تفصيلياً** (المحافظة، المدينة، الشارع)
- 🛍️ **جدول المنتجات المشتراة** (الاسم، كود المنتج SKU، اللون، المقاس، الكمية، السعر)
- 💳 **طريقة الدفع وملاحظات التحويل** (دفع عند الاستلام COD / فودافون كاش / انستاباي)
- 💰 **المبلغ الإجمالي** (شامل تكلفة الشحن)

---

## 👤 2. المطلوب منك (خطوة بخطوة) — User Requirements
لتفعيل النظام، يتوجب عليك تجهيز **Bot Token** و **Chat ID** من تطبيق تليجرام عبر الخطوات البسيطة التالية:

### 🔹 الخطوة (1): إنشاء بوت جديد على تليجرام
1. افتح تطبيق تليجرام وابحث عن `@BotFather`.
2. اضغط على **Start** ثم أرسل الأمر: `/newbot`.
3. اكتب اسماً للبوت، مثلاً: `DEEB STORE Orders`.
4. اكتب يوزر نيم للبوت ينتهي بـ `bot`، مثلاً: `deeb_store_orders_bot`.
5. سيقوم `@BotFather` بإرسال **HTTP API Token** لك (شكل التوكين: `7890123456:AAE_xXxXxXxXxXxXxXxXxXxXxXxXxX`).
6. قم بنسخ هذا التوكين **(Bot Token)**.

### 🔹 الخطوة (2): الحصول على رقم الشات الخاص بك (Chat ID)
1. افتح البوت الجديد الذي أنشأته على تليجرام واضغط **Start**.
2. ابحث في تليجرام عن بوت اسمه `@userinfobot` أو `@GetChatID_BOT`.
3. اضغط **Start** وسيظهر لك رقم يسمى **Id** (مثال: `123456789`).
4. قم بنسخ هذا الرقم **(Chat ID)**.
> 💡 *ملاحظة:* إذا أردت استلام الإشعارات في **جروب تليجرام خاص بك وبالفريق**: قم بإضافة البوت للجروب وترقيته كـ **Admin**، ثم احصل على Chat ID الخاص بالجروب (يبدأ بـ `-100...`).

### 🔹 الخطوة (3): حفظ التوكين في لوحة تحكم الأدمن
1. افتح لوحة تحكم الأدمن بالمتجر وتوجه إلى: **إعدادات المتجر → تبويب إشعارات تليجرام**.
2. ضع الـ **Bot Token** والـ **Chat ID**.
3. قم بتفعيل الخيار والضغط على **زر الحفظ والتجربة**.

## 💻 3. ما سيتم برمجته وتطويره (AI Agent Implementation Plan)

### ⚙️ أ) إنشاء ملف الخدمة `lib/telegram.ts`
برمجة دالة إرسال الرسائل عبر API تليجرام الرسمي:
- `sendTelegramOrderNotification(order)`: بناء الرسالة الفاخرة المنسقة وإرسالها فورياً.
- `sendTelegramTestNotification(token, chatId)`: إرسال رسالة تجريبية لاختبار تفعيل البوت.

### 🔌 ب) إنشاء API Route للتجربة والإرسال `/api/telegram/test`
- إنشاء نقطة نهاية خلفية تستقبل طلبات الاختبار من لوحة التحكم للتأكد من سلامة الـ Token والـ Chat ID قبل حفظهما.

### 🛍️ ج) الربط التلقائي بصفحة إتمام الطلب `app/(store)/checkout/page.tsx`
- بمجرد نجاح دالة `createOrder(orderPayload)`، سيتم استدعاء خدمة تليجرام تلقائياً في الخلفية بدون تأخير تجربة العميل.

### 🎛️ د) تطوير لوحة تحكم تليجرام في `app/(admin)/admin/settings/page.tsx`
إضافة قسم مخصص في إعدادات الأدمن يتيح:
- مفتاح تفعيل/تعطيل إشعارات تليجرام (Toggle Switch).
- حقل إدخال **Telegram Bot Token**.
- حقل إدخال **Telegram Chat ID**.
- زر اختبار فوري: **"إرسال إشعار تجريبي الآن 📲"**.
