# 01 — نظرة عامة على DEEP STORE

## 🎯 ما هو المشروع؟

**DEEP STORE** هو متجر إلكتروني متكامل لبيع ملابس الـ Streetwear الفاخرة في مصر والوطن العربي.  
المتجر مبني بـ **Next.js 15** ويدعم إدارة المنتجات، الطلبات، والمدفوعات بشكل كامل.

---

## 🛠️ التقنيات المستخدمة

### Frontend
| التقنية | الإصدار | الوظيفة |
|---|---|---|
| **Next.js** | 15.3 | إطار عمل React الرئيسي (App Router) |
| **React** | 19 | مكتبة UI |
| **TypeScript** | 5.6 | كتابة الكود بأنواع آمنة |
| **Tailwind CSS** | 3.4 | نظام التصميم |
| **Framer Motion** | 11 | الأنيميشن والحركات |

### Backend / Database
| التقنية | الإصدار | الوظيفة |
|---|---|---|
| **Firebase Firestore** | 11 | قاعدة البيانات الرئيسية |
| **Firebase Auth** | 11 | نظام المصادقة (Admin) |
| **Firebase Admin SDK** | 12 | عمليات السيرفر |
| **Cloudinary** | 2.5 | تخزين ورفع الصور |

### مكتبات مساعدة
| المكتبة | الوظيفة |
|---|---|
| **react-hook-form** | إدارة الفورمات |
| **zod** | التحقق من البيانات |
| **sonner** | الإشعارات (Toasts) |
| **lucide-react** | الأيقونات |
| **swiper** | السلايدر |
| **clsx + tailwind-merge** | دمج الكلاسات |

---

## 🏪 وظائف المتجر الرئيسية

### للعميل (Store)
- ✅ عرض المنتجات مع الفلترة بالكاتيجوري
- ✅ صفحة تفاصيل المنتج مع معرض الصور + Zoom
- ✅ سلة المشتريات (Cart) مع حفظ في localStorage
- ✅ قائمة المفضلة (Wishlist)
- ✅ إتمام الطلب مع عدة طرق دفع
- ✅ طلب عبر واتساب مباشرة
- ✅ مشاركة المنتج (Share)
- ✅ منتجات مشابهة في صفحة المنتج
- ✅ Quick Buy من الكارد مباشرة
- ✅ شريط إعلانات متحرك

### للأدمن (Admin)
- ✅ داشبورد مع Charts (مبيعات + توزيع الطلبات)
- ✅ إدارة المنتجات (إضافة، تعديل، حذف)
- ✅ إدارة الطلبات وتغيير حالتها
- ✅ إدارة الكاتيجوريز
- ✅ إدارة العملاء
- ✅ إدارة الشحن
- ✅ رسائل التواصل
- ✅ إعدادات المتجر الكاملة (CMS)

## 🌐 الصفحات الرئيسية

```
/                   ← الصفحة الرئيسية
/products           ← صفحة تفاصيل المنتج
/shop               ← متجر المنتجات كله
/cart               ← السلة
/checkout           ← إتمام الطلب
/about              ← عن المتجر
/contact            ← تواصل معنا
/order-success      ← نجاح الطلب
/privacy            ← سياسة الخصوصية
/terms              ← الشروط والأحكام
/admin/*            ← لوحة الإدارة (محمية)
```
