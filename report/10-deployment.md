# 10 — بناء ونشر المتجر (Build & Deployment)

يمكن نشر مشروع **DEEP STORE** بسهولة على أي منصة استضافة تدعم Next.js مثل **Vercel** (الخيار الموصى به) أو **Netlify** أو خادم خاص (VPS).

---

## 🏗️ 1. البناء المحلي والتشغيل (Local Build & Test)

قبل القيام بنشر المتجر للإنتاج، يُنصح دائماً بالتحقق محلياً من سلامة الكود والـ Types بالخطوات التالية:

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل عملية ما قبل البناء (نسخ جداول المقاسات والأصول)
npm run prebuild

# 3. بناء نسخة الإنتاج
npm run build
```

إذا نجحت عملية البناء بدون أخطاء TypeScript أو ESLint، يمكنك تشغيل نسخة الإنتاج محلياً:
```bash
npm run start
```

---

## ☁️ 2. النشر على منصة Vercel (الموصى بها)

منصة Vercel هي البيئة الرسمية والمثالية لـ Next.js وتدعم الـ Serverless Functions تلقائياً.

### خطوات النشر:
1. قم بربط مستودع الكود (GitHub Repository) بحساب Vercel الخاص بك.
2. اختر مشروع Next.js.
3. **أضف متغيرات البيئة (Environment Variables):**
   - انسخ كافة المتغيرات الموجودة في ملف `.env.local` وأضفها في إعدادات المشروع على Vercel.
   - ⚠️ **انتبه للـ Private Key الخاص بـ Firebase:**
     - عند إضافة `FIREBASE_PRIVATE_KEY` في إعدادات Vercel، تأكد من إضافتها بعلامات الاقتباس المزدوجة وبشكل صحيح، أو استبدال علامات السطر الجديد `\n` بأسطر حقيقية إذا واجهت مشكلة في قراءتها.
4. اضغط على **Deploy**. سيقوم Vercel ببناء المشروع ونشره وتوفير رابط URL سريع ومجاني للوصول.

## 🛠️ 3. الأخطاء الشائعة وحلها (Troubleshooting)

### 1. خطأ `failed to compile` بسبب الـ quotes في JSX:
- **المشكلة:** استخدام علامات اقتباس مثل `"` أو `'` بشكل مباشر داخل نصوص الـ JSX يسبب كسر البناء في React.
- **الحل:** استبدالها بكيانات HTML المكافئة مثل `&quot;` أو `&#39;` أو كتابة النص داخل كود جافا سكريبت `{""}`.

### 2. خطأ الـ `TypeScript Types` عند الـ Build:
- **المشكلة:** وجود تحذيرات صارمة من TypeScript أو استخدام `any` في أماكن غير مسموح بها.
- **الحل:** كتابة الواجهات والـ Types الصحيحة وتجنب الـ `any` بقدر الإمكان لضمان استقرار التطبيق.

### 3. تعذر الاتصال بـ Firebase Admin SDK على السيرفر:
- **المشكلة:** الـ Private Key يتم قراءته بشكل خاطئ بسبب تعامل Vercel مع الأسطر الجديدة `\n`.
- **الحل:** تأكد من إعداد تهيئة مفتاح Firebase في كود السيرفر كالتالي:
  ```javascript
  const privateKey = process.env.FIREBASE_PRIVATE_KEY?.replace(/\\n/g, '\n');
  ```
